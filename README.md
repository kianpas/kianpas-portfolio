# kianpas-portfolio

Next.js 기반의 개인 포트폴리오 웹사이트입니다. 저의 프로젝트와 블로그 게시물들을 확인하실 수 있습니다.

## 🚀 기술 스택

- **프레임워크**: Next.js
- **언어**: TypeScript
- **스타일링**: Tailwind CSS
- **컨텐츠**: Markdown

## ✨ 시작하기

패키지 매니저는 **npm**입니다 (`package-lock.json`).

```bash
npm install
npm run dev
```

## 📄 문서

- `AGENTS.md` — AI 에이전트용 작업 규칙과 검증 절차
- `DESIGN.md` — 디자인 시스템 (색·타이포·레이아웃·공통 컴포넌트)
- `NOTES.md` — 작업 메모와 남은 할 일
